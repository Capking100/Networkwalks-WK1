# Networkwalks-WK1
How to set your lab as a cybersecurity analyst.
The tools used are oracle virtual-box and kali Linux
The oracle virtual box was download using a trusted website.
The machine network was set to a natnetwork with a 10.0.0.0.1
After that the KALI LINUX was also downloaded from a trusted source.
The machine was extracted and launched to the virtual box for set up.
The network of the machine was set to a natnetwork and applied.
The machine was launched and got the Wired connection setup in the interface.
If you are using the new version of KALI LINUX, there is a code to type in the terminal to get the connection done easily which is "sudo nmcli connection modify "Wired connection 1" ipv4.dad.timeout 0". 
After that, the network is set and can be used to browse without any interruption.
The next is to take the snapshot for later usage.
Power off the machine and go to the snapshot area to run it. 
Use a description to symbolized it as a snapshot.
